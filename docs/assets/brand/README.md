# Tapioca brand assets

The Tapioca mascot combines a tapioca pearl with a terminal prompt. It should
feel friendly to beginners without losing its developer-tool personality.

## Files

| File | Use |
| --- | --- |
| `tapioca-logo.png` | Full-resolution transparent source |
| `tapioca-icon-master.png` | Tightly cropped master icon |
| `tapioca-icon-512.png` | README, documentation, and social assets |
| `tapioca-icon-128.png` | App and navigation icon |
| `tapioca-favicon-64.png` | Browser favicon source |
| `tapioca-logo-chroma.png` | Original generated source; keep for future edits |

## Palette

| Role | Approximate color |
| --- | --- |
| Pearl | `#FBE1B3` |
| Espresso outline | `#2A1119` |
| Purple accent | `#A000F5` |
| Magenta accent | `#F229E8` |
| Cyan highlight | `#63ECF2` |

Keep adequate space around the pearl, preserve the dark outline, and avoid
placing the transparent mark directly on visually busy imagery. The icon may
be used without a wordmark. Do not add platform logos or recolor individual
facial features.

The initial bitmap was generated with OpenAI's built-in image generation tool
and converted to a transparent PNG using local chroma-key removal.
